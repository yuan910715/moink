# MoInk 使用指南

引导页网址：**https://topyuan.top/moink**。

## 部署

`MoInk-guide-package.zip` 只包含两个文件，将它们一起上传至服务器的 `moink/` 目录：

- `index.html`：引导页，样式和脚本内置。
- `MoInk-welcome-static-552x768.png`：欢迎卡静态图片。

「保存欢迎卡至本地」是直接打开这张 PNG 的普通链接，没有下载属性，也不在手机上生成图片。打开原图后可长按保存。微信中的长按菜单需在真机确认。

此次仅更新本地文件和部署包，未上传服务器。

## 欢迎卡

新图是 **MoInk-welcome-static-552x768.png**，可直接上传至设备创作页刷入墨水屏。尺寸为 552×768，是横版欢迎卡顺时针旋转 90°的结果。保留完整构图，避免裁切二维码。

中文实际使用加粗的思源黑体（Noto Sans SC），接近手机无衬线字体风格；它是已绘制进 PNG 的固定字形。引导页继续使用系统字体。二维码指向 https://topyuan.top/moink。

横版工作稿、四色预览、二维码工具与摄影素材保留在本地，不包含在部署包内。

## 验证

已验证实际中文字形为 Noto Sans SC，中文提示区域相较旧图有 3310 个像素变化；二维码区域保持不变。已用独立解码器确认欢迎卡二维码地址，并验证图片旋转、尺寸及引导页的普通图片链接。
